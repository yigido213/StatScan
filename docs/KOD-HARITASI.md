# Kod haritası (StatScan / Kovan) — yeni sohbetteki Claude için

Bu dosya, hafızası olmayan yeni bir Claude oturumunun projeyi 5 dakikada kavraması içindir. **Önce `CLAUDE.md` (kurallar + çalışma günlüğü), sonra bu dosya.** Günlük "ne zaman neyi yaptık" der; bu dosya "kod nerede, nasıl çalışır" der. Bir şeyi değiştirince bu dosyayı da güncelle (ilgili satırı).

## Genel yapı
- **Uygulama**: Windows Electron uygulaması "Kovan" (StatScan'in yeni adı). Çoğu araç yalnız masaüstünde çalışır; arayüz tarayıcıda da açılır ama host gerektiren araçlar orada kapalıdır.
- **Tek dosya arayüz**: `app/StatScan.html` (~1,4 MB). HTML + CSS + tüm arayüz JS'i. Elle baştan yazma; hedefli düzenle. Motor parçaları `src/engine/NN-*.js` içinde yazılır, `node tools/inject.mjs` ile HTML'e yerleştirilir.
- **Host (ana süreç)**: `app/desktop/host.js` tek dosya, içinde bağımsız modüller (hepsi `const XMOD = (() => {...})()`): `OBFMOD`, `COMPMOD` (derleyici), `ACCESSMOD` (sahip/Notlarım/Yönetim — **güvenlik hassas, dokunma**), `SYSMOD` (görev yöneticisi, ağ), `LOLMOD` (Blitz — eski adı League Asistanı), `FLOWMOD` (Uygulama Akışı; GAMEMOD'dan önce, MEMMOD diliminin dışında), `GAMEMOD` (Oyun Ayarlayıcı), `MEMMOD` (RAM analizi). Sıra önemli: `mem-host.cjs` kaynak taramasında MEMMOD..riskyList dilimine bakar; GAMEMOD MEMMOD'dan önce durmalı.
- **Köprü**: `app/desktop/preload.js` arayüze dar bir API verir (`window.statscanHost.lolXxx(...)`); argümanları burada şekillendirilir (arayüz yol/URL gönderemez). `app/desktop/app.js` pencere + modül bağlama (ör. `lol: { dataDir }`).
- **Güncelleme (YENİ: depodan doğrudan)**: yayın = `main`'deki `app/` değişimi; ayrıntı aşağıda 'Depodan doğrudan güncelleme'. ESKİ yol (`latest.json` + imzalı `.ssu`, `tools/make-ssu.mjs`, `app.js` DEFAULT_FEED) yalnız son geçiş paketi ve `update.repo=false` kaçış yolu için duruyor; artık paketleme yapılmaz. `app/` altına yeni dosya/uzantı eklenecekse `REPOMOD.EXT_OK`/`LIM` sınırlarına bak; kod yine host.js/StatScan.html içine yazılır.
- Arayüz modülleri `MODULES` listesinde (kategori: Güvenlik / Windows / Oyun / Minecraft / Kodlama); her araç `#app-<id>` paneli + bir `kovanXxx` IIFE'si. İngilizce çeviri `KT()`/EN sözlüğü (Türkçe metin eklersen EN karşılığı da ekle; `ui-lang.mjs` Türkçe kalıntı tarar).

## Depodan doğrudan güncelleme (REPOMOD + `app.js` `repoHandOff`/`checkRepo`)
- **Akış**: `checkRepo` → `REPOMOD.check({dataDir})`: (1) `GET /repos/yigido213/StatScan/git/ref/heads/main` (son commit; aynıysa dur = 1 istek), (2) commit → kök ağaç → `app` girdisinin ağaç sha'sı (= SÜRÜM KİMLİĞİ; yalnız `app/` değişirse değişir), (3) `app` ağacı `?recursive=1`, (4) her dosya `raw.githubusercontent.com/<commit>/app/<yol>` (commit'e sabit) → boyut + git blob sha1 listeyle eşleşmeli, `.js`/HTML betik/JSON yalnız derlenir (shebang/BOM serbest, hiçbir şey çalıştırılmaz), (5) `userData/kovan-repo/builds/<ağaç12>/` altına yazılır + `.kovan-build.json` (her dosyanın sha1/boyutu), `state.json` güncellenir. Sonra `offerRestart` ('Sürüm <commit7> hazır').
- **Açılış**: `app.js start()` ilk iş `repoHandOff(ctx)`: `repoEnabled()` (config `update.repo !== false`) + `REPOMOD.pickBoot()` (dosyaları yeniden doğrular; `boot.tries` ≥ 2 ise geri alır) → depodaki `desktop/app.js`'i `require` edip `start({...ctx, root: yapı, repoRoot, repo:{tree,commit,msg}})` çağırır; yükleyicinin `ctx.version/source/updater/bundledRoot/publicKey` ALANLARI AYNEN kalır (yükleyici `cleanOld/markGood` bunlara güveniyor). Yapı `require` edilemezse → `rollback` + uygulamayla gelen yola düşer; `start()` fırlatırsa → `rollback` + `app.relaunch()`. Pencere açılıp 4 sn sonra `markGood(tree)` sayacı sıfırlar. Devredilen `app.js` kendi içinde `ctx.repoRoot` görüp tekrar devretmez.
- **Durum** (`state.json`): `current`, `previous` (yalnız bu ikisinin klasörü tutulur), `checked`, `boot`, `bad` (çöken ağaçlar; tekrar indirilmez → 'blocked'), `lastRollback`. Bozuk/yanlış `state.json` = boş durum (çökmez).
- **Sınırlar/denetimler**: `LIM` (60 dosya, dosya 8 MB, toplam 32 MB), `EXT_OK`, `SEG_OK` (yol parçaları), `REQUIRED` dosyalar, sembolik bağlantı/alt modül/büyük-küçük harf çakışması reddedilir, `HOSTS` yalnız api.github.com + raw.githubusercontent.com (yönlendirme dahil her sıçramada denetlenir). Kaynak taraması testte: kabuk/exec/eval yok.
- **Güven**: imza YOK; kök = GitHub hesabı + `main` (bkz. CLAUDE.md 'Sürüm yayınlama'). Anonim GitHub API sınırı 60/saat/IP; normal denetim 1 istek (değişmediyse), güncellemede ~4 JSON + dosya sayısı kadar raw (raw sayılmaz).
- **Kapatma/sıfırlama**: config `update.repo=false`; Yardım > 'Depodan yüklenen sürümü sıfırla…' (`REPOMOD.reset`).
- Testler: `repoupd-host.cjs` (sahte GitHub; `--live`: GERÇEK GitHub, `NODE_USE_ENV_PROXY=1 NODE_EXTRA_CA_CERTS=...` gerekebilir), `repoupd-boot.cjs` (gerçek `app.js` açılış devri, sahte Electron). DENENMEDİ: gerçek Windows/Electron, gerçek `.ssu` → depo geçişi.
